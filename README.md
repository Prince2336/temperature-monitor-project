# temperature-monitor-project
A Python Temperature Monitor and Alarm Checker for ND1 Mechatronics Engineering.
Temperature Monitor and Alarm Checker

1. Project Title

Temperature Monitor and Alarm Checker using Python.

2. What It Does

This project is a simple Python program that monitors five temperature readings entered by the user.

It calculates the highest temperature, lowest temperature, and average temperature. It also checks whether any reading exceeds the example safe limit of 60°C.

If the temperature exceeds the limit, the program displays a warning and reports the machine status as CRITICAL. Otherwise, the status is NORMAL.

3. How to Run It
	1.	Install Python or open the program in a Python IDE.
	2.	Open the file temperature_monitor.py.
	3.	Run the program.
	4.	Enter five temperature readings in Celsius.
	5.	View the results and any warnings.

4. Sample Output

Example readings: 35, 42, 48, 65, 82.
	•	Highest temperature: 82°C
	•	Lowest temperature: 35°C
	•	Average temperature: 54.4°C
	•	Machine status: CRITICAL
	•	Alerts: Readings 4 and 5 are too high.

5. My Own Twist

I added a feature that identifies the exact reading numbers that exceed the temperature limit. I also added input validation so the program asks for a valid number if the user enters text instead.
